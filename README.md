## 🧱 Stack

| Layer     | Tech                                   |
| --------- | -------------------------------------- |
| Framework | Nuxt 4                                 |
| UI        | Nuxt UI                                |
| Database  | Drizzle ORM on Cloudflare D1           |
| Auth      | Better Auth                            |
| i18n      | @nuxtjs/i18n                           |
| SEO       | @nuxtjs/seo                            |
| Hosting   | Cloudflare Workers, R2 (media storage) |

## 🎨 Design

The interface follows the **Fluent** design language.
